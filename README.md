# AdRobot

Тестовое задание: работа с рекламным трекером Keitaro через его Admin API.

1. **Создание кампаний.** На вход название, гео и оффер. Создаётся кампания с двумя потоками: указанные страны уходят на Google, все остальные на выбранный оффер.
2. **Редактор офферов.** В потоках кампании можно добавлять и удалять офферы, доли пересчитываются автоматически, изменения отправляются в Keitaro по кнопке.

Стек: FastAPI, SQLAlchemy, Postgres на бэке, React и TypeScript на фронте.

Подробности: [ТЗ с принятыми решениями](docs/superpowers/specs/2026-11-19-adrobot-design.md), [план реализации](docs/superpowers/plans/2026-11-19-adrobot.md).

## Запуск

Нужен только Docker (с Docker Compose), и он должен быть запущен.

```sh
./setup.sh
```

На Windows — двойной щелчок по `setup.bat`.

Скрипт спросит API-ключ Keitaro, создаст `.env` (пароль входа и секрет JWT сгенерирует сам), соберёт и запустит контейнеры и в конце напишет адрес, логин и пароль.

Вручную то же самое:

1. Скопировать настройки и заполнить их:
   ```sh
   cp .env.example .env
   ```
   Обязательно поменять в `.env`: `KT_API_KEY`, `APP_PASSWORD`, `JWT_SECRET`.
2. Запустить:
   ```sh
   docker compose up -d --build
   ```
3. Открыть http://localhost:8080 и войти с `APP_LOGIN` / `APP_PASSWORD` из `.env`.

Если порт 8080 занят, поменяйте `APP_PORT` в `.env` и повторите шаг 2.

Остановить: `docker compose down`. Удалить вместе с базой: `docker compose down -v`.

## Создание кампании

1. На странице **Campaigns** нажмите **New campaign**.
2. **Name** — название кампании. К нему спереди добавится префикс из `CAMPAIGN_NAME_PREFIX` в `.env` (если он задан).
3. **Geo** — страны, которые уйдут на Google. Вводите двухбуквенный код страны и **нажимайте Enter** (или запятую): код превратится в плашку, например `MX`. Так по одной добавьте все нужные страны.
   - Можно вставить сразу список: `MX, AU, RO`.
   - Регистр не важен: `mx` станет `MX`.
   - Неправильный код (не две латинские буквы) останется в поле с подсказкой «Use 2-letter codes, e.g. MX».
   - Убрать страну: крестик на плашке или Backspace в пустом поле.
   - Код, введённый без Enter, не считается: кнопка **Create** останется неактивной.
4. **Offer** — начните вводить название или ID оффера и выберите его из списка.
5. Проверьте блок **Will be created**: Flow #1 — ваши страны → google.com, Flow #2 — все остальные → выбранный оффер.
6. Нажмите **Create**. Кампания появится в списке, офферы в ней можно менять через **Edit offers**.
