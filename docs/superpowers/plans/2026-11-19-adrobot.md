# AdRobot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создаватель кампаний Keitaro (2 потока: гео → Google, остальные → оффер) и редактор офферов в потоках с пересчётом долей, черновиком и Push/Cancel.

**Architecture:** FastAPI-бэк держит в Postgres наши кампании, их потоки и историю офферов потока (synced-состояние + черновик). Вся работа с Keitaro — через один async-клиент. Пересчёт долей — чистая функция. React-фронт ходит только в наш бэк.

**Tech Stack:** Python 3.12, uv, FastAPI, SQLAlchemy 2 (async, asyncpg), Alembic, pydantic-settings, httpx, pytest + pytest-asyncio + respx; React 19 + TypeScript + Vite, TanStack Query, react-router, react-select; Postgres 18; docker-compose.

**Spec:** `docs/superpowers/specs/2026-11-19-adrobot-design.md`

## Global Constraints

- Вход создавателя — только название, гео (список ISO-кодов), ID оффера.
- Домен/группа/источник — из `.env` по названию: `KT_DOMAIN=kylovoa.com`, `KT_GROUP=FORTESTS`, `KT_TRAFFIC_SOURCE=FORTESTS`.
- Keitaro Admin API: `{KT_URL}/admin_api/v1`, заголовок `Api-Key: {KT_API_KEY}`.
- Поток 1: позиция 1, фильтр `country` mode `accept`, редирект на `https://google.com`. Поток 2: позиция 2, оффер с долей 100.
- Доли — целые, сумма активных = 100; Push запрещён иначе и при 0 активных офферов.
- Ничего не уходит в Keitaro без явного Push (кроме создания кампании).
- Фронт вызывает только `/api/*` нашего бэка.

## Review Focus

1. Fetch потока, где в Keitaro сумма долей ≠ 100 → импортируем как есть, пересчёт не запускаем, Push заблокирован с причиной. (Task 6)
2. Add оффера, который уже активен в потоке → 409, дубля нет. (Task 7)
3. Remove последнего активного оффера → Push заблокирован «нужен хотя бы один оффер». (Task 2, Task 7)
4. Гео `"mx, AU,mx"` → `["MX","AU"]`; `"MEX"` или пусто → 422. (Task 5)
5. Кампания удалена в Keitaro → fetch отдаёт 410, локальные данные не тронуты. (Task 6)
